For windows

1. Install VisualStudio Build tools, Qt6, and cmake 

2. Make sure you set your env variables for Qt 
    a. Qt6_DIR=path\to\qt\install\<toolchain>
    b. QT_PLUGIN_PATH=path\to\qt\install\plugins

- install openCV to c:\opencv\

  The prebuilt OpenCV Windows pack is found automatically. If you see

      Found OpenCV Windows Pack but it has no binaries compatible with your
      configuration

  then the pack's own OpenCVConfig.cmake does not recognise your Visual Studio
  version. CMake works around this by using the per-toolset config in
  c:\opencv\build\x64\vcNN\lib instead, so make sure that folder exists; you can
  also point at it directly with -DOpenCV_DIR=C:/opencv/build/x64/vc17/lib.

3. Run the build with the camerasdk path as the first argument
./WinBuild.bat <Path-to-camera-sdk-path>
