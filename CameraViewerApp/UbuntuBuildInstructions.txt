Build Instructions (Ubuntu)
===========================

1) Install dependencies
-----------------------
sudo apt update && sudo apt install -y cmake git build-essential 
qt6-base-dev qt6-base-private-dev qt6-tools-dev qt6-svg-dev 
libgl1-mesa-dev libjpeg-dev libopencv-dev python3-opencv

NOTE: Qt 6.9 or newer is required. The application uses Qt APIs that older
releases do not provide (for example QImage::flipped, added in Qt 6.9), so the
qt6-base-dev in older Ubuntu archives - 6.4 on Ubuntu 24.04 - is too old and
the build fails on missing headers and members.

If apt gives you an older Qt, install Qt 6.10 separately and point CMake at it:

  cmake -B build -DCAMERA_SDK_PATH=../OptiTrack_Camera_SDK_3.4.1_Final_Ubuntu
        -DCMAKE_PREFIX_PATH=/path/to/Qt/6.10.0/gcc_64

The Qt online installer or aqtinstall both work. CI installs Qt this way; see
.github/workflows/ci.yml.


2) Clone repository
-------------------
Navigate to the directory where you want the project, then run:

git clone https://github.com/fuzzylogic88/Production-Lens-Validation.git
cd Production-Lens-Validation


3) Build project
----------------
chmod +x build.sh
./build.sh ../OptiTrack_Camera_SDK_3.4.1_Final_Ubuntu


(Optional) Enable color camera support (FFmpeg)
----------------------------------------------
Install FFmpeg:
sudo apt install -y ffmpeg

Build with FFmpeg support:
./linuxBuild.sh ../OptiTrack_Camera_SDK_3.4.1_Final_Ubuntu --ffmpeg


4) Configure network (required)
-------------------------------
Set the camera network interface to Link-Local Only:

Settings → Network → Wired (camera port) → IPv4 → IPv4 Method → Link-Local Only


5) Run application
------------------
./build/CameraViewerApp
